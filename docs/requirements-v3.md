# KKS-Forge 要件定義書 v3.0

> 株式会社小出環境サービス向け Claude Code 開発エージェント環境
> CloudCLI（Claude Code UI）ベース・ポート3300

---

## 1. プロジェクト概要

### 1.1 名称
**KKS-Forge**（ケーケーエス・フォージ）

開発（Forge = 鍛冶場）専用の運用環境であることを示す。

### 1.2 目的

- HermesのLLM伝言ゲーム問題を回避し、Claude Code に直接GUIで指示する開発環境を構築する
- スマホ・PCのブラウザから完全に操作できる
- 記憶の永続性、複数プロジェクト管理、Git・ファイル操作を一元化
- Hermes（会話・監視用）と並走させ、役割を明確に分離する

### 1.3 設計方針

**当初構想**: Web UI + Telegram bot + 記憶MCPを自作
**確定方針**: 既存OSS **CloudCLI（旧 Claude Code UI）** をベースに採用、不足機能だけ薄く補完

採用理由：
- 大桃さんの要望のほぼ全てをカバー（Web/モバイル対応、プロジェクト管理、Git・ファイル操作、MCP管理、ターミナル内蔵、プラグイン、セッション継続、自動承認設定）
- GitHub 10,900 stars、AGPL-3.0、活発にメンテナンス継続中（直近リリース 2026/5/13）
- 自作で半日〜数日かかる実装が `npx` 一発で動く
- Claude Code の `~/.claude` を直接読み書きするので、既存セットアップとの整合性が高い
- プラグインシステムでスケジュール実行（cloudcli-cron）等が後付け可能

## 2. 全体構成

```
┌────────────────────────────────────────────┐
│            大桃さん（PC / スマホ）            │
└───────────────────┬────────────────────────┘
                    │ HTTPS (forge.kkshd.jp 想定)
                    ▼
        ┌──────────────────────────────┐
        │  既存Nginx (リバースプロキシ)  │
        │  - Basic認証                 │
        │  - 許可IP制限                │
        │  - SSL終端                   │
        └────────────┬─────────────────┘
                     │ HTTP (loopback)
                     ▼ 127.0.0.1:3300
        ┌──────────────────────────────┐
        │  CloudCLI (Node.js)          │
        │  - Web UI (React + Vite)     │
        │  - プロジェクト一覧           │
        │  - チャット / ターミナル      │
        │  - File / Git エクスプローラ  │
        │  - MCP管理                   │
        │  - プラグイン拡張点          │
        └────────────┬─────────────────┘
                     │
                     ▼
        ┌──────────────────────────────┐
        │  Claude Code (既設)           │
        │  - 非rootユーザー実行         │
        │  - --dangerously-skip-perms   │
        │  - ~/.claude を直接利用       │
        │  ↓ MCP                       │
        └────────────┬─────────────────┘
                     │
                     ▼
        ┌──────────────────────────────┐
        │  mcp-memory-service          │
        │  (記憶の永続化)               │
        │  SQLite + ChromaDB           │
        └──────────────────────────────┘
```
